## 1. การคำนวณอ้างอิงด้วยมือ

ค่าทดลอง: VCC = 12 V, R1 = 100 kΩ, R2 = 22 kΩ, RC = 2.2 kΩ, RE = 1 kΩ,
β = 100, VBE = 0.70 V

```
VTH = 12 × 22 / (100 + 22)      = 2.1639 V
RTH = 100 × 22 / (100 + 22)     = 18.0328 kΩ
IB  = (2.1639 − 0.70) / (18.0328k + 101 × 1k)
    = 1.4639 / 119032.8         = 12.298 µA
IC  = 100 × 12.298 µA           = 1.2298 mA
IE  = 101 × 12.298 µA           = 1.2421 mA
VE  = 1.2421 mA × 1 kΩ          = 1.2421 V
VB  = 1.2421 + 0.70             = 1.9421 V
VC  = 12 − 1.2298 mA × 2.2 kΩ  = 9.2943 V
VCE = 9.2943 − 1.2421           = 8.0522 V
```

ตรวจสอบย้อนกลับ: VB − VE = 1.9421 − 1.2421 = 0.7000 V = VBE ✓
และ VCE = 8.052 V > VCE_SAT (0.2 V) → Active ✓

# Lab 03 — สามโหมดไบอัส

## 5. ค่าอ้างอิงอิสระ (คำนวณมือจากสมการในใบงาน)

ใช้ร่วมกัน: VCC = 12 V, RC = 2.2 kΩ, β = 100, VBE = 0.70 V
Tolerance ตามใบงาน: IC ±0.01 mA, VCE ±0.02 V

### A1 — Divider (R1 = 100 kΩ, R2 = 22 kΩ, RE = 1 kΩ)

เหมือน Lab 02 ทุกหลัก: VTH = 2.1639 V, RTH = 18.0328 kΩ,
IB = 12.2986 µA, IC = 1.2299 mA, VCE = 8.0522 V

### A2 — Fixed (RB = 1 MΩ)

```
IB  = (12 − 0.70) / (1000 kΩ × 1000)  = 11.30 µA
IC  = 100 × 11.30 µA                  = 1.1300 mA
IE  = 101 × 11.30 µA                  = 1.1413 mA
VE  = 0 V (Emitter ลงกราวด์)
VB  = 0 + 0.70                        = 0.7000 V
VC  = 12 − 1.1300 mA × 2.2 kΩ         = 9.5140 V
VCE = 9.5140 − 0                      = 9.5140 V
```

### A3 — Emitter (RB = 1 MΩ, RE = 1 kΩ)

```
IB  = 11.30 / ((1000 + 101×1) kΩ × 1000) = 10.2634 µA
IC  = 1.0263 mA ,  IE = 1.0366 mA
VE  = 1.0366 mA × 1 kΩ                   = 1.0366 V
VB  = 1.0366 + 0.70                      = 1.7366 V
VC  = 12 − 1.0263 × 2.2                  = 9.7421 V
VCE = 9.7421 − 1.0366                    = 8.7054 V
```

### A4 — Emitter (RB = 1 MΩ, RE = 2 kΩ)

```
IB  = 11.30 / ((1000 + 101×2) kΩ × 1000) = 9.4010 µA
IC  = 0.9401 mA ,  IE = 0.9495 mA
VE  = 1.8990 V ,  VB = 2.5990 V
VC  = 12 − 0.9401 × 2.2                  = 9.9318 V
VCE = 8.0328 V
```

**ทำนายก่อนรัน:** IC ของ A4 ต้อง **ลด** จาก A3 เพราะพจน์ `(β+1)·RE`
ใหญ่ขึ้นเป็นสองเท่าขณะที่ RB คงเดิม → กระแสฐานลด (0.9401 < 1.0263) ✓

### A5 — Fixed, RB = 0

ต้องได้ HTTP 400 + ข้อความเรื่อง RB และต้องไม่มีผลลัพธ์ค้างจากรอบก่อน

## 8. กรณีขอบที่ตรวจเพิ่ม

| กรณี | อินพุต | ผลที่ได้ |
|---|---|---|
| โหมดไม่รู้จัก | `mode=foo` | HTTP 400 + `โหมดไบอัสไม่รู้จัก: foo` (หน้าเว็บยังแสดงฟอร์มปกติ) |
| ไม่ส่งโหมด | ไม่มีช่อง `mode` | HTTP 400 + `กรุณาเลือกโหมดไบอัส` |
| ช่องที่ไม่ใช้มีค่าขยะ | `mode=fixed`, `R1=abc` | HTTP 200 คำนวณปกติ (โหมดนี้ไม่ใช้ R1) |
| ขาดช่องที่โหมดต้องใช้ | `mode=emitter` ไม่ส่ง `RB` | HTTP 400 + `กรุณากรอก RB (kΩ)` |
| Cutoff ของ Divider | R2 = 1 kΩ | VB = 0.119 V (= VTH), IC = 0, VCE = 12 V, warning |
| ขอบ Saturation | fixed, RC = 10.4430 kΩ | VCE = 0.199 V → Saturation + warning |
| เหนือขอบ | fixed, RC = 10.4420 kΩ | VCE = 0.201 V → Active ไม่มี warning |

> หมายเหตุเรื่องขอบ: โปรแกรมเทียบค่า VCE ดิบกับ 0.2 V แต่หน้าเว็บปัดทศนิยม
> 3 ตำแหน่ง ดังนั้น VCE = 0.2004 V จะแสดงเป็น "0.200 V" แต่ยังรายงาน Active
> (เพราะ 0.2004 > 0.2) — เป็นธรรมชาติของเกณฑ์ที่มีจุดตัด ไม่ได้ปัดค่าก่อนเทียบ
