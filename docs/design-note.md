# Design Note — Lab 02

## ปัญหา

นักศึกษาต้องเห็นความแตกต่างระหว่างหน้า HTML ธรรมดากับ Web Application
ที่มี Backend คำนวณจริง

## แนวทาง

แยกความรับผิดชอบ 3 ชั้น

1. **Presentation** — `templates/index.html` + `static/style.css`
   แสดงฟอร์มและผลลัพธ์ ไม่มีสมการ
2. **Transport** — `app.py` แปลง HTTP form เป็น Python และเลือก template
3. **Engineering** — `dc_bias.py` เป็นโมดูลบริสุทธิ์ที่ทดสอบแยกได้

## Lab 03 — สามโหมดไบอัส

### ทางเลือกที่พิจารณา

| เรื่อง | ทางเลือก | ที่เลือก | เหตุผล |
|---|---|---|---|
| รูปแบบผลลัพธ์ | คืน `dict` ทุกโหมด เทียบกับคง dataclass + `as_dict()` | คืน `dict` | ตรงใบงาน ("คีย์ร่วม `vb_v, vc_v, vce_v, ic_ma`"), template เขียนครั้งเดียว, route ไม่ต้องรู้จักชนิดข้อมูลของโดเมน |
| การสลับช่องตามโหมด | ซ่อนด้วย CSS ฝั่ง server เทียบกับ render เฉพาะช่อง | ซ่อนด้วย CSS (`field--unused`) | `static/` เป็น CSS ล้วนตามกติกา repo, ค่าที่กรอกไว้ไม่หาย, กด Calculate ครั้งเดียว |
| โหมดไม่รู้จัก | ตีความเป็น Divider เทียบกับ error | error 400 | การเดาเงียบ ๆ ทำให้ผู้ใช้เข้าใจผิดว่าคำนวณโหมดที่ต้องการแล้ว |

### การแยก `_assemble`

จุดที่ต่างกันระหว่างสามโหมดมีเพียง **สมการกระแสฐาน** ส่วนที่เหลือ
(`IC = β·IB`, `IE = (β+1)·IB`, `VE`, `VB`, `VC`, `VCE`, region, warning)
เหมือนกันหมด จึงรวมไว้ที่ `_assemble()` ตัวเดียว ฟังก์ชันโหมดแต่ละตัวมีหน้าที่
แค่คำนวณ `IB` แล้วส่งต่อ ผลคือเพิ่มโหมดใหม่ในอนาคต = เพิ่มฟังก์ชัน 5 บรรทัด
บวกหนึ่งบรรทัดใน `MODE_FIELDS` ไม่ต้องแตะ template หรือ route

### Cutoff ของ Divider

ในโหมด Divider ค่า VB ตอน Cutoff คือ VTH (ขั้วฐานถูกตรึงด้วยตัวต้านทาน
สองตัว) ไม่ใช่ `VE + VBE` เพราะยังไม่มีกระแสฐานไหล จึงคงพฤติกรรมเดิมของ
Lab 02 ไว้ (VB = 0.119 V ในกรณีทดสอบ R2 = 1 kΩ)
